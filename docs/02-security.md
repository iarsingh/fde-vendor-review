# Security

Reads `data/packets.csv` from disk. The sample has no account numbers. A real file should keep bank details in the system of record and pass this tool only a yes/no that they changed.

Decisions are blocked_sanctions, blocked_incomplete, manual_review, or ready_for_human. There is no approved state, and the renderer throws if that word appears.

Rollback is stopping the process. The ERP vendor master is unchanged.
